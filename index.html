Technical Documentation

Architecture

  • Frontend: single-page app using HTML/CSS/JavaScript
  • Map stack: Leaflet + OpenStreetMap tiles + custom overlays
  • Charts: Chart.js for analytics visualization
  • Persistence: localStorage fallback and optional Supabase sync

Data Model

  • `users`: auth, favorites, interaction history, role flags
  • `businesses`: listing metadata, deals, and reviews
  • `reviews`: user, rating, sentiment signals, dates
  • `activityLog`: chronological user events

Security and Quality

  • Client-side validation for auth and review submission
  • Moderation queue for low-rated/high-dislike reviews
  • Accessibility supports keyboard and ARIA labels
  • Exported JSON reports for judge verification

Supabase Setup

  • Create table `app_state(state_key text primary key, payload jsonb, updated_at timestamp)`
  • Set `window.TOWNSQUARE_SUPABASE_URL` and `window.TOWNSQUARE_SUPABASE_ANON_KEY`
  • Enable RLS policy for your authenticated demo workflow
  • App will auto-fallback to local mode if keys are missing

Quick Help

Browse Businesses

  • Use "Explore" to see all local businesses
  • Use category filters to narrow by type
  • Use review filters to find highly-rated businesses
  • Search by name or category

Reviews & Ratings

  • Click "Review" on any business card
  • Rate 1-5 stars and write your experience
  • Complete the "I'm not a robot" verification
  • Like/dislike other reviews to help the community

Favorites

  • Click the favorite button to save places
  • View all favorites in "My Favorites" tab
  • Get personalized recommendations based on your favorites

Hot Deals

  • View current deals and special offers
  • Each listing shows its current promotion

Profile

Dark Mode

  • Preference is saved automatically
